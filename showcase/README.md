# Learner showcase

Finished capstones (Week 12) can be added here as **worked examples** so that later cohorts can see what good looks like, and so that learners get public credit for their work.

## How to add yours

1. Create a folder `showcase/<your-name>-<track>/` (for example `showcase/amina-outbreak/`).
2. Include: a `README.md` (use the template in [Week 12](../weeks/week-12-capstone.md)), your scripts, and **small** outputs (tables, figures under 500 KB) generated **only from the course's synthetic data**.
3. Remove personal information (local file paths, usernames, e-mail addresses).
4. Open a pull request. A reviewer will check that it runs from scratch and is respectful and accurate.
5. Add yourself to [CONTRIBUTORS](../contribute/CONTRIBUTORS.md).
