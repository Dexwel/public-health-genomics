# Contributing

Thank you for helping improve the Public Health Genomics course!

**You do not need to know Git.** Start with the full guide: [contribute/README.md](contribute/README.md).

Quick start:

1. **Spotted a problem or have an idea?** Open an issue and pick a form (*Suggest a change*, *A lab command did not work*, *Propose a resource*).
2. **Want to fix a page yourself?** Open the file on GitHub, click the pencil icon, edit, and propose the change.
3. **Want to make bigger changes?** Fork, branch, run `python scripts/lint_course.py`, open a pull request.

Please read the [style guide](contribute/style-guide.md), the [data policy](contribute/data-policy.md) (**no real personal or patient data, ever**) and the [Code of Conduct](CODE_OF_CONDUCT.md).

Every change is checked automatically and reviewed by a subject-matter expert before it reaches learners.
